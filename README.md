# **Money Management Application**

## Personal Proposal

This application will help users manage their personal finances by creating a profile, setting a monthly budget, and tracking both payments and earnings. Users will be able to add and delete payments or earnings with type and amount, set the budget for the current month's payment, and view spending progress through percentages. At the end of each month, the application will reset the budget, store the old records, and provide a breakdown of spending and earnings by category to give users a clear picture of their money habits.

The main users of this application will be students and young adults who are starting to live on their own and want to learn effective money management skills. This project is of personal interest to me because I recently began living independently on campus, away from my family. I want to train myself in budgeting, identify unnecessary expenses, and save toward future goals such as travel. Building this application will not only improve my programming skills but also help me practice responsible financial planning in my own life.


## User Stories  

- As a user, I want to be able to create a profile with my name and starting amount.  
- As a user, I want to be able to add and delete payments with type and amount.  
- As a user, I want to be able to view my list of payments.  
- As a user, I want to be able to add and delete earnings with type and amount.  
- As a user, I want to be able to view my list of earnings.  
- As a user, I want to be able to see the percentage of my budget left.  
- As a user, I want to be able to see the percentage breakdown of my spending and earnings by category.  
- As a user, I want to be able to reset the month and store the old records.
